# Nomenclature des fichiers – Locomotion Lab

Ce document définit les règles définitives de nommage des fichiers dans le vault Obsidian.
Ces règles sont conçues pour être :
- lisibles par un humain
- stables dans le temps
- compatibles Git / Markdown / site web
- indépendantes de l’emplacement des fichiers

---

## Règles générales

- Pas de numéros dans les noms de fichiers
- Pas de dates (sauf journaux personnels)
- Pas d’abréviations cryptiques
- Accents autorisés
- Majuscule au début
- Tiret long `–` pour structurer
- Le type de note n’est PAS dans le nom du fichier (sauf MOC)

---
### Note source (document)

**Format** : Type de document – Sujet principal.md


**Exemples**
- Rapport – Résonance biologique.md
- Article – Humming et oxyde nitrique.md
- Livre – La santé par la course à pied.md

---
### Note cadre (idée structurante)

**Format** : Idée centrale formulée clairement.md


**Exemples**
- Corps humain comme système oscillatoire.md
- Hormèse comme principe adaptatif.md

---
### Note concept

**Format** : Nom du concept.md

**Exemples**
- Mécanotransduction.md
- Humming.md
- Impédance mécanique.md

---
### Note mécanisme

**Format** : X → Y.md

**Exemples**
- Vibration acoustique → activation FAK.md
- Humming → washout du NO sinusien.md
- Exposition au froid → activation sympathique.md

---
### Note donnée scientifique

**Format** : X – résultat clé.md

**Exemples**
- Humming – augmentation du NO nasal (~×15).md
- Chant de gorge – pression artérielle élevée.md

---
### Note pont / synthèse

**Format** : X et Y – relation.md

**Exemples**
- Vibration et exposition au froid – mécanismes communs.md
- Respiration et régulation autonome.md

---
### MOC (Map of Content)

**Format** : MOC – Thème.md

**Exemples**
- MOC – Vibration.md
- MOC – Respiration.md
- MOC – Exposition au froid.md

---
### Article / production éditoriale

**Format** : Titre éditorial complet.md

**Exemples**
- Vibration acoustique et physiologie humaine.md
- Respirer pour moduler l’état de conscience.md

---
## Fichiers non-Markdown (PDF, images)

- Tous les fichiers non `.md` vont dans `90_Attachments/`
- Les PDF utilisent la convention : auteur_année_motcle.pdf

---
## Principe fondamental

Les dossiers sont une aide visuelle.
La structure réelle du savoir repose sur :
- les liens
- les MOCs
- la nomenclature claire

Ce document fait foi pour toute création future.
