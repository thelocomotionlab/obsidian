# 🎬 Gabarits éditoriaux — reels & carrousels

> **Principe fondateur : un reel et un carrousel sont des _productions_.**
> Ils vivent dans `40_Productions`, avec `format: reel` ou `format: carrousel`.
> Ils obéissent donc à la métrique de santé du coffre : *le nombre de notes réutilisées*.
>
> Conséquence : la cadence Instagram n'est pas une tâche concurrente du coffre. C'est ce qui le met sous pression et l'empêche de devenir inerte.

---

## 1. L'échelle des affirmations

Avant tout gabarit, situer ce qu'on s'autorise à dire.

| Niveau | Nature | Exemple | Ce qu'il exige du coffre |
|---|---|---|---|
| **0** | Géométrie / mécanique visible dans le plan | « la base d'appui disparaît latéralement » | rien |
| **1** | Expérience première personne, annoncée comme telle | « au bout de 8 m mes avant-bras lâchent avant mes épaules » | rien |
| **2** | Mécanisme nommé correctement | « anti-rotation », « information plantaire », « plan frontal » | une note `20_Notes` existante |
| **3** | Effet, adaptation, transfert, causalité | « ça renforce X », « ça transfère sur Y » | une note **`statut: vérifiée`** + sa source **`fiabilité` renseignée** |

### 🚧 La porte
> **Aucune affirmation de niveau 3 ne sort du coffre si la note n'est pas `statut: vérifiée`.**
>
> `vérifiée` = j'ai lu la source primaire moi-même, pas un résumé, pas un rapport IA.
> Si ce n'est pas le cas : je redescends en niveau 0-2 et je décris la **contrainte** au lieu de l'**effet**. Une contrainte s'observe ; un effet se source.

Cette règle est le prolongement direct de la règle *Fait ≠ hypothèse* du mode d'emploi, appliquée au public.

## 2. Gabarits de reels (10-20 s)

Répartition cible : **4 reels de niveau 0-2 pour 1 reel de niveau 3.**
Le reel de niveau 3 n'est jamais écrit à partir de rien — il est **extrait d'un carrousel déjà produit**.

### A. Contrainte — *niveau 0*
Le plus solide, le moins risqué, le plus réutilisable.
```
[Ce qui est facile dans la version standard.]
[Ce que cette surface / contrainte impose ici.]
[La conséquence géométrique, en une phrase.]
```
→ Aucune note requise. Décrit ce que la caméra montre.

### B. Progression — *niveau 1*
Le plus enregistré et le plus envoyé en DM. À surpondérer.
```
Comment j'y suis arrivé :
1. [étape]  2. [étape]  3. [étape]
Compte [durée réaliste].
```
→ Zéro risque d'erreur scientifique : c'est du vécu, annoncé comme tel.

### C. Échec — *niveau 1*
Le plus commenté.
```
Ce que tu ne vois pas : les [n] tentatives d'avant.
Ce qui lâche en premier chez moi : [ça].
```

### D. Question calibrée — *niveau 0*
```
[Une phrase de contexte.]
Toi, tu tiens combien de [mètres / secondes / répétitions] ?
```

### E. Mécanisme — *niveau 2, exceptionnellement 3*
Le seul gabarit qui touche au coffre.
```
[Le geste.] Ce qui travaille réellement :
▸ [mécanisme nommé]
▸ [mécanisme nommé]
▸ [le différenciant : pieds nus / nasal / etc.]
[Nuance ou limite, une phrase.]
```
→ **Chaque puce doit pointer vers une note existante.** Si la note n'existe pas, le gabarit est interdit — utiliser A ou B à la place.
→ La ligne « nuance ou limite » n'est pas optionnelle : c'est elle qui distingue le compte des comptes affirmatifs.

## 3. Gabarits de carrousels (7-10 slides)

> **Un carrousel = un MOC rendu, ou une source rendue.** Jamais une page blanche.
> Déclencheur : un MOC atteint ~5 notes → il est mûr pour un carrousel.

### F. Mécanisme — *le socle*
Rend une chaîne de 3-5 notes atomiques liées.
| Slide | Contenu |
|---|---|
| 1 | Affirmation contre-intuitive ou chiffre. Lisible en vignette. |
| 2 | Le problème / l'idée reçue |
| 3-7 | Une note atomique par slide, ≤ 25 mots |
| 8 | Slide de synthèse — **celle qu'on screenshot** |
| 9 | Renvoi vers l'article complet |

### G. Idée reçue → correction — *le plus envoyé en DM*
```
1. « [Idée reçue formulée telle qu'on l'entend] »
2. Ce qu'on en déduit habituellement
3. Ce que dit la source
4-6. Le mécanisme réel
7. Ce qui reste vrai dans l'idée reçue  ← ne jamais sauter
8. Synthèse
```
→ La slide 7 évite le ton « tout le monde a tort », qui attire la contradiction plus que le partage.

### H. Protocole — *le plus enregistré*
```
1. Le résultat visé, chiffré
2. Prérequis / à qui ça s'adresse
3-7. Une étape par slide, avec durée
8. Erreurs fréquentes
9. Comment savoir que ça marche (le critère observable)
```

### I. Lecture d'étude — *le différenciant, niveau 3*
Rendu direct d'une note `10_Sources`. **Réservé aux sources `fiabilité` renseignée.**
```
1. L'affirmation qui circule
2. L'étude : qui, quand, combien de sujets
3-5. Ce qu'elle montre réellement
6. Ce qu'elle NE montre PAS  ← le cœur du gabarit
7. Ce qu'on peut en faire quand même
8. Synthèse
```
→ Reproduit exactement ce qui a été fait sur [[Dallam 2018 — Respiration nasale et VO2max]] : c'est le format le plus difficile à copier pour un compte concurrent.

### J. Terrain & données — *l'actif unique*
Le seul gabarit que personne d'autre ne peut produire : GPX, FC, D+, live-tracking.
```
1. Le chiffre brut (km / D+ / durée)
2. La carte ou le profil
3-6. Une décision par slide, avec la donnée qui l'a motivée
7. Ce qui n'a pas marché
8. Synthèse
```

## 4. Spécifications de forme

**Reels**
- 7-15 s pour maximiser les replays ; 20-30 s max pour les gabarits narratifs
- Boucle : image de fin ≈ image de début
- Image la plus forte dans la première seconde, jamais un carton titre seul
- Export natif (pas d'enregistrement d'écran), 9:16, 1080p
- Incrustation dans **la même langue** que la légende

**Carrousels**
- 4:5 (1080 × 1350)
- Slide 1 lisible en vignette : ≤ 8 mots, contraste fort
- Avant-dernière = slide de synthèse (celle qui est screenshotée)
- ≤ 25 mots par slide

**Légendes**
- Ligne 1 = deuxième hook, ~40 caractères visibles, sans emoji
- Puces avec marqueur typographique (`▸`, `↳`), pas emoji
- 5 hashtags max, cibles 10 k-500 k publications
  `#primalmovement` · `#quadrupedalmovement` · `#barefoot` · `#trailrunning` · `#locomotionlab`
  (emplacements 1-3 fixes, 4 variable, 5 = archive de marque)

## 5. Le cycle

```
Cours / lecture / terrain
   → 00_Inbox
   → 10_Sources (fiabilité renseignée)
   → 20_Notes (titre = affirmation, statut: graine → mûre → vérifiée)
   → 30_MOC (cristallise vers 5 notes)
   → 40_Productions
        ├── Article        (assemblage complet)
        ├── Carrousel      (le MOC rendu, gabarits F-J)
        └── Reels ×2-3     (extraits du carrousel, gabarit E)
```

**Un article ⇒ 1 carrousel + 2-3 reels de niveau 3.**
Le reste de la semaine est couvert par les gabarits A-D, qui ne coûtent rien au coffre.

Rythme tenable : **2 reels + 1 carrousel par semaine**, dont ~1 production de niveau 3 tous les 10 jours.
